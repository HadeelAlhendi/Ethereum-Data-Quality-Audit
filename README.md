# Ethereum Data Quality Audit Framework 🛡️

## 📌 Professional Statement
This repository showcases my approach to **Data Quality Engineering** as a Computer Science Graduate (Honors). It contains specialized SQL audits designed to monitor and safeguard data integrity within the Ethereum blockchain using Google BigQuery.

## 🔍 Audit Scope & Findings
- **Integrity Checks:** Identifying null values in critical transaction fields (From/To addresses).
- **Anomaly Detection:** Monitoring zero-value transaction spikes. 
    * *Insight:* Recent audit revealed that ~58% of daily transactions are zero-value, a key metric for network behavior analysis.
- **Scalability:** Optimized for Big Data environments (millions of records).
